# Seasonal-Agriculture-Performance-Analysis

## 📌 Project Overview

**Seasonal Agriculture Performance Analysis** is a data analysis project developed using Python to analyze agricultural data and identify patterns in **crop yield, production, profitability, water usage, soil conditions, and environmental factors**.

The project analyzes **4,000 farm records** and determines which crop-season combinations perform best based on profitability and agricultural performance.

## 🎯 Objectives

* Analyze agricultural performance across different seasons and crops.
* Identify profitable crop-season combinations.
* Study the relationship between environmental and soil conditions and crop yield.
* Analyze water usage and water efficiency.
* Perform data cleaning and exploratory data analysis (EDA).
* Visualize important agricultural trends and patterns.

## 📊 Dataset

The dataset contains **4,000 farm records** with information such as:

* Farm and location details
* Crop and season
* Farm area
* Rainfall and temperature
* Humidity and sunlight
* Soil pH and soil moisture
* Nitrogen, phosphorus, and potassium
* Irrigation method
* Fertilizer and pesticide usage
* Seed quality
* Crop yield and production
* Market price
* Cost, revenue, and profit
* Water usage and efficiency
* Disease and pest risk

## 🧹 Data Preprocessing

The dataset contained missing values in some columns, including:

* Rainfall
* Soil Moisture
* Yield

Missing values were handled using **median imputation** to maintain the dataset while reducing the effect of outliers.

## 📈 Key Analysis

The project analyzes:

* Average crop yield

### 🏆 Key Finding

Based on the analysis, **Kharif + Sugarcane** was identified as the most profitable crop-season combination in the dataset, with an average profit of approximately **₹10,00,790.81**.
